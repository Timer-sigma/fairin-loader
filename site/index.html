Fairin Loader

Быстрый и лёгкий загрузчик модов для Minecraft 1.14 → 1.26.x

Официальные Mojang-маппинги вместо тысяч хардкодов. Ядро не знает ни одной версии — поэтому лоадер работает и с будущими релизами. Один remap на версию, кэш, нулевая рефлексия в горячем пути.

Возможности

⚡ Быстрый

Remap всего клиента (~10 000 классов) — единожды на версию, дальше кэш. Запуск игры после лоадера — <0.3 с.

🧩 Без версий в ядре

Никаких if (version == 1.21). Всё берётся из version JSON и официальных маппингов — 1.14.4+ и все будущие 26.x/27.x.

🖥️ Клиент и сервер

Выделенный сервер через fairin-server-launch.jar: bundler 1.18+ и жирный jar 1.14–1.17, server_mappings, start.bat из коробки.

🪄 Хуки без Mixin

Декларативные хуки (fairin-hooks.json) вплетаются ASM'ом в безопасные точки. Тики мода — 20 раз/сек напрямую через MethodHandles.

📦 Простой формат модов

Обычный jar, одна аннотация @FairinMod, методы @OnInit/@OnTick. Никаких JSON-манифестов.

🚀 Ванильный лаунчер

Устанавливается как обычный профиль «fairin-версия». Никаких сторонних лаунчеров не требуется.

Установка — клиент

  1. Скачайте FairinInstaller.exe и запустите (SmartScreen: «Подробнее → Выполнить в любом случае», файл не подписан).
  2. Режим Client, папка %APPDATA%\.minecraft (подставлена сама), выберите версию из списка.
  3. Нажмите Install. В лаунчере появится профиль fairin-<версия>.
  4. Выберите профиль и играйте. Моды кладите в .minecraft/mods/.

Консольный вариант: java -jar fairin-loader-0.1.0.jar --mc 1.21.11

Установка — выделенный сервер

  1. В инсталлере переключитесь на Server, выберите папку и версию → Install. Или консолью: java -jar fairin-loader-0.1.0.jar --mc 1.21.11 --server --dir C:\servers\my
  2. Согласитесь с EULA: eula.txt → eula=true.
  3. Запустите start.bat (Windows) или start.sh (Linux). Для 1.20.5+ нужна Java 21+, для 1.18–1.20.4 — Java 17+.
  4. Сервер скачает jar Mojang, один раз ремапнет (кэш в fairin-cache/) и стартует. Моды — в mods/.

Как у Fabric: тонкий fairin-server-launch.jar + конфиг fairin-server.json — при новых версиях просто меняйте mcVersion.

Разработка модов

import com.fairin.api.FairinMod;
import com.fairin.api.OnInit;
import com.fairin.api.OnTick;

@FairinMod(id = "example", name = "My Mod", version = "1.0")
public class MyMod {

    @OnInit
    public void init() {
        System.out.println("Привет, Fairin!");
    }

    @OnTick
    public void tick() {
        // 20 раз в секунду на клиенте
    }
}
  • Один jar — один класс с @FairinMod; кладётся в mods/.
  • Игровые классы доступны в официальных именах Mojang: net.minecraft.client.Minecraft.getInstance() — лоадер ремапит весь Minecraft.
  • @OnInit — до открытия окна (клиент и сервер); @OnTick — каждый клиентский тик.
  • Сборка мода: обычный Gradle-проект, зависимость compileOnly на fairin-loader.

FAQ

Работает с Forge/Fabric-модами?

Нет. Fairin — самостоятельный загрузчик со своим лёгким форматом модов.

Почему первый запуск дольше?

Один раз на версию: скачиваются маппинги, jar ремапится (~10–15 с). Дальше — кэш.

Какие версии поддерживаются?

Клиент и сервер 1.14.4 — 1.26.x (официальные маппинги доступны с 1.14.4; на более старых лоадер запустится, но без хуков в игровые классы).

Какая Java нужна?

Ванильный лаунчер выберет сам. Для своих серверов: 1.20.5+ → Java 21, 1.18–1.20.4 → Java 17, 1.14–1.17 → Java 8+.

Антивирус ругается на exe

Файл не подписан. Добавьте в исключения или соберите exe сами (см. README проекта).
